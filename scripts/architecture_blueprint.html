1. Executive Platform Architecture & Construction Overview

The Byzid Apparels Factory Operations Platform is a high-speed telemetry and financial analytics dashboard engineered for industrial garment manufacturing. Built on Next.js 16.2 (Turbopack) and React 19, the website provides floor-to-executive visibility across 4 sewing lines, live hourly piece counts, dynamic Contribution Margin (CM) financial calculations, and interactive visual physics simulations.

Security & Loop-Prevention Implementation

Edge middleware protects all routes. Background polling aborts immediately if 401 Unauthorized occurs:

// Edge Route Proxy Gateway (src/proxy.js) export function middleware(req) { const session = req.cookies.get('ba_session')?.value; const isAuth = session === hashPasscode(process.env.DASHBOARD_PASSCODE); if (!isAuth && !req.nextUrl.pathname.startsWith('/login')) { return NextResponse.redirect(new URL('/login', req.url)); } } // 401 Flash Prevention (useKpiData.js & ClientAutoRefresh.jsx) if (res.status === 401) { if (window.location.pathname !== '/login') { window.location.href = '/login'; } return null; // Stop polling loop completely }
